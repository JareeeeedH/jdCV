# Jared Huang — Personal CV Website

Standalone HTML/CSS recreation of [Jared Huang's CakeResume](https://www.cake.me/resumes/s--zY1rmtYWsocmKRlVGjnXKA--/ok0922056886).

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

No build step or framework required.

## Structure

```
/
├── index.html
├── css/style.css
├── js/main.js
├── assets/
│   ├── profile/
│   └── projects/
└── README.md
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Then visit `http://localhost:8080`.

## Content source

All text, section order, and project links match the CakeResume reference. Project/profile images are local copies of publicly accessible CakeResume CDN assets.
